# 模型部署完全学习手册

> 从 Hugging Face 等平台下载开源模型，并用 Python 部署运行的全部方法
> 本手册只讲**通用部署方法**，覆盖所有主流方案，不针对特定机器配置

## 一、部署全景图（先看懂整体）

```
┌─────────────────────────────────────────────────────────────────────┐
│                    模型部署的完整链路                                  │
│                                                                     │
│  ① 模型下载           ② 推理引擎            ③ 对外服务               │
│  ┌──────────┐       ┌────────────┐       ┌─────────────────┐       │
│  │HF官网/镜像│       │  Ollama    │       │  OpenAI兼容API   │       │
│  │GitHub    │──────▶│ Transformers│─────▶│  /v1/chat/...   │──────▶│ 你的Agent
│  │ModelScope│       │  vLLM      │       │  FastAPI自定义   │       │
│  └──────────┘       │  llama.cpp │       └─────────────────┘       │
│     权重文件          └────────────┘        统一协议，应用无感        │
│  (safetensors/GGUF)     加载到显存/内存                              │
└─────────────────────────────────────────────────────────────────────┘
```

**核心认知**：你的应用（Agent、聊天机器人）永远只通过 **API 接口** 跟模型交互。
底层用哪个引擎部署，对应用是**透明的**——这就是为什么可以"云端换本地，只改一个 base_url"。

## 三、必须搞懂的核心概念

### 1. 权重文件（模型 = 一堆数字）
训练完成后，模型的"知识"全部存储在**权重矩阵**里，通常是几 GB 到几百 GB 的浮点数文件。

| 格式 | 后缀 | 说明 |
|------|------|------|
| safetensors | .safetensors | HF 主流格式，安全快速 |
| PyTorch | .bin / .pt | 旧格式 |
| GGUF | .gguf | llama.cpp 专用，可量化 |
| ONNX | .onnx | 跨平台推理格式 |

### 2. 量化（Quantization）—— 省显存的魔法
把权重从高精度（16bit/32bit）压缩成低精度（8bit/4bit）：

| 量化 | 精度 | 显存占用 | 质量损失 |
|------|------|---------|---------|
| 无量化 FP16 | 16bit | 2GB/10亿参数 | 无 |
| INT8 | 8bit | 1GB/10亿参数 | 很小 |
| INT4 | 4bit | 0.5GB/10亿参数 | 可感知，可接受 |

> **速算公式**：模型显存 ≈ 参数量 × 字节数
> 7B 模型 FP16 = 7 × 2GB ≈ 14GB；INT4 = 7 × 0.5GB ≈ 3.5GB

### 3. 推理引擎（Inference Engine）
负责把权重加载进显存、执行前向计算（生成 token）的软件层。
不同引擎的优化方向不同：Ollama 追求易用、vLLM 追求吞吐、transformers 追求灵活。

### 4. 关键参数理解
| 参数 | 含义 | 影响 |
|------|------|------|
| max_new_tokens | 最多生成多少 token | 太长会超时/爆显存 |
| temperature | 采样温度 | 越低越确定，越高越发散 |
| top_p | 核采样 | 控制候选词范围 |
| context_length | 上下文长度 | 影响能"记住"多少对话 |

## 四、学习路径建议

```
推荐学习顺序：

第1步：Ollama（05分钟出结果，建立信心）
   ↓
第2步：Transformers（理解底层原理，学会加载/量化/推理）
   ↓
第3步：嵌入模型（掌握 RAG 的向量化基础）
   ↓
第4步：llama.cpp（理解 GGUF 量化原理）
   ↓
第5步：vLLM（生产级部署，服务化）
   ↓
第6步：FastAPI 服务化（把模型封装成标准 API）
```

每一篇文档都是**独立完整**的，可以单独学习，也可以按顺序系统学。

## 六、5 分钟快速开始

### 零门槛体验（Ollama）
```bash
# 1. 安装 Ollama（https://ollama.com/download）
# 2. 下载中文模型
ollama pull qwen2.5:3b

# 3. 开始聊天
ollama run qwen2.5:3b
# >>> 你好，用 Python 写一个快速排序代码

# 4. 用 Python 调用
python -c "
import ollama
r = ollama.chat(model='qwen2.5:3b', messages=[{'role':'user','content':'你好'}])
print(r['message']['content'])
"
```
