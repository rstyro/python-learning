## 什么是 AI Agent？

**Agent = LLM + 记忆 + 工具 + 规划**

```
传统 LLM 调用：  用户 → LLM → 回答文本
Agent：          用户 → LLM → 思考 → 调用工具 → 观察 → 再思考 → ... → 最终回答
```

Agent 与普通 LLM 对话的核心区别：
1. **自主决策**：Agent 能自己决定下一步做什么，而不是被动回答
2. **工具使用**：Agent 能调用搜索引擎、数据库、API 等外部工具
3. **记忆能力**：Agent 能记住之前的对话和操作结果
4. **规划能力**：Agent 能将复杂任务分解为多个步骤并逐步执行

## 环境准备

```bash
# 激活虚拟环境
.venv\Scripts\activate

# 设置utf8环境变量，防止requirements.txt有中文注释编码问题
$env:PYTHONUTF8=1

# 安装所有依赖
pip install -r requirements.txt

# 设置 API Key（以 DeepSeek 为例）
# Windows PowerShell：
$env:AI_DEEPSEEK_API_KEY = "your-api-key-here"
# 或在系统环境变量中设置
```
